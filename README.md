# Atividade Aula 03 - CSS

- **Tema da página:** A página possui o tema "Resenha da Fiel", representando um encontro fictício de torcedores do Corinthians.

- **Cores escolhidas:** Foram utilizadas principalmente as cores preto, branco e tons de cinza, criando uma identidade visual relacionada às cores do Corinthians.

- **Seletores utilizados:** Foram utilizados seletores por tag, como `body`, `header`, `nav` e `footer`; seletores por classe, como `.card`, `.img` e seletor por ID, como `#sobre`.

- **Margin, padding e border:** O `margin` foi utilizado para criar espaços externos entre os elementos e seções. O `padding` foi utilizado para criar espaços internos nos cards, cabeçalho, menu e rodapé. O `border` foi utilizado principalmente nos cards e imagens.

- **Dificuldade encontrada:** Uma das dificuldades foi observação que o sr me colocou na ultima atividade que foi organizar corretamente a estrutura semântica da página,. O problema foi resolvido reorganizando os elementos dentro do `body`, separando corretamente `header`, `nav`, `main` e `footer`.
